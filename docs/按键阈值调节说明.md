# Sobel 按键阈值调节

日期：2026-11-02。所有修改仅在D:/gx2026/project/camera_sdram_tft_sobel；彩色、灰度与时序验证副本未修改。

## 使用

| 输入 | 顶层信号 | FPGA引脚 | 作用 |
|---|---|---|---|
| 输入1 | key_up_n | M16 | 每次有效按下，阈值增加8 |
| 输入2 | key_down_n | E15 | 每次有效按下，阈值减少8 |

按键低有效，使用板载按键的外部上拉。M16/E15不支持本次器件配置的内部弱上拉，QSF没有启用该选项。初值128；最小0、最大2040，达到端点后饱和，不溢出回绕。两键在同一个时钟产生有效按下脉冲时相互抵消。

33MHz像素域内执行两级同步、20ms（660000周期）稳定电平消抖。长按只触发一次，必须有效松开再按才能再次触发；松开也消抖。按下前抖动、松开抖动、短毛刺不计数。

threshold_requested立即累计有效按键步进；threshold_active在下一次frame_prepare（原始扫描h=v=0的消隐区）更新，避免同一帧使用多个阈值。复位后恢复128。数据处理与显示延迟仍为1060周期。

默认二值模式中阈值越大，保留边缘越少；阈值越小，纹理和噪声越多。阈值为0时，因比较为M>=T，内部有效区包括平坦区域也会显示白色，这是定义允许的结果。强度显示模式不使用阈值比较，因此这两个按键不改变强度图像。

## 实现与接口

- 新增rtl/image_process/button_press_pulse.v：clk、rst_n、key_n输入，press_pulse输出。双触发器同步，稳定电平计数消抖，只在稳定按下时输出一拍。
- 新增rtl/image_process/sobel_threshold_keys.v：输入clk/rst_n/frame_prepare/key_up_n/key_down_n，输出threshold_requested[10:0]、threshold_active[10:0]。参数INITIAL_THRESHOLD默认128、MAX_THRESHOLD默认2040、DEBOUNCE_CYCLES默认660000。
- 修改sobel_filter.v：新增threshold[10:0]动态输入，替换固定参数比较。九像素窗口、梯度计算、流水级数和有效坐标不变。
- 修改sobel_video_pipeline.v：新增key_up_n/key_down_n输入；在同一个clk_tft域内实例化控制器，threshold_active连接Sobel。保留THRESHOLD参数作为上电初值；新增BUTTON_DEBOUNCE_CYCLES参数供测试缩短消抖。
- 修改顶层ov5640_sdram_hdmi_tft.v：新增两个按键端口并连接视频链路。
- 修改QSF：添加两个新RTL；PIN_M16→key_up_n、PIN_E15→key_down_n；IO_STANDARD均为3.3-V LVTTL。

全部阈值处理在33MHz像素域，无需让11位阈值总线跨域。采集、SDRAM、灰度及TFT扫描时序保持。没有加入自动连发或额外按键功能。
